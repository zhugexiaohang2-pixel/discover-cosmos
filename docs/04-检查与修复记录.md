# DiscoverCOSMOS 检查与修复记录

日期：2026-10-13。按“修复并增强可靠性”的范围处理报告与实现，保留现有产品形式。本轮修改前的文件保存在 [原始备份](../archive/original-2026-10-13.tar.gz)。

## 已确认问题

P1 表示主要流程或渲染受阻；P2 表示状态、科学表达或维护可靠性问题。下表记录可由代码、计算或实际执行确认的缺陷。

| 优先级 | 原问题与证据 | 修改 |
|---|---|---|
| P1 | 主场景清屏 alpha=1，合成 sky×(1−alpha) 恒为 0 | 透明清屏，GPU 验证背景 alpha=0、实体保留 |
| P1 | 将相机 −Z 前向当作后向；只更改纵向分量，没有完整逆 boost | 使用运动轴点积和完整向量变换，独立数学与 GPU 像素对照 |
| P1 | 关闭相对论后全屏采样同一方向 | β=0 仍按每个像素射线采样，逐像素与关闭开关对照 |
| P1 | 首次深链接在 GL 声明前执行路由，触发暂时性死区 | 调整启动顺序，实际地球阅读深链接通过 |
| P1 | 卡牌烘焙调用 renderer.dispose(target)，实际销毁 renderer | 改为 target.dispose，并用 finally 清理临时资源 |
| P2 | 星空随相机重复捕获且使用方向变换不一致 | 固定世界系立方体，只初始化捕获一次 |
| P2 | 行星多普勒增益来自太阳方向，可能使整个实体变暗 | 明确相对论仅作用于无限远星空，有限实体保留几何显示 |
| P2 | 太阳重复套用压缩与放大，直径占比约 37.2% | 固定为 4.5%，增加尺度契约检查 |
| P2 | 运行时尺度实现与测试分叉，ED 修改后轨道线未更新 | 共用可调参数函数，尺度修改重建并返回俯瞰 |
| P2 | 接近方向随相机变化；抵达后重设角度导致状态交接不连续 | 保存接近方向，从实际偏移恢复环绕状态 |
| P2 | 声称支持点击球体，实际只绑定标签；名称仅显示色点 | 增加 Raycaster 单击选择和可聚焦的名称按钮 |
| P2 | 一程下限用了 2D/c，HUD 显示 74.58 分钟 | 改为 D/c，显示 37.29 分钟，并明确其显示坐标参考含义 |
| P2 | 每帧诊断及无效 HDR 字节回读可能产生错误或假零值 | 诊断显式开启、每两秒采样；HDR 提示改用字节目标 |
| P2 | shader 使用反向 smoothstep 边界，行为未定义 | 改为 1−smoothstep(0,0.25,r²) |
| P2 | 依赖运行时 CDN，测试摘要硬编码 384，失败细节不足 | 固定本地依赖与许可证，增加资源检查，动态汇总并输出失败信息 |
| P2 | “一天”混同自转周期与太阳日，卫星数量过时 | 标作“自转一周”，按 NASA 最新页面核对卫星数并附日期 |

β=0.98 时，原正前向公式算出 D≈0.1005，正确前向值约 9.9499；这不是曝光调参可以修正的问题。相同 β 下，完整逆变换还必须处理横向分量。

除表内问题外，还修正图鉴返回逻辑、未知 debug 文本的 HTML 注入风险、错误提示的可见状态，以及普通模式的多余诊断。HUD 增加宽度约束；窄屏下将其与选中信息卡分开，参数面板支持在有限高度内滚动。运行时模块已拆出共用视觉、着色器和渲染目标逻辑，降低两页实现分叉风险。

## 检查结果与剩余范围

三个核心数值套件共 577 项断言通过；资源与文档检查由 verify.sh 另行动态汇总。真实 GPU 和页面回归共 48 项通过。证据、环境和重跑方法见 [验证报告](03-验证报告.md)。

本轮没有引入新产品页面、小程序、后台或线上部署。跨浏览器、真实手机、低端 GPU 和性能专项留待对应环境验证。当前已确认缺陷均已处理；这些剩余环境不能用本次结果代替。

## 本地运行环境接手（2026-10-13）

当前机器有 Node.js v24.21.0，但系统 Python 与 Git 缺少 Apple 命令行工具。新增 scripts/serve.mjs 与 start.command，以 `npm start` 启动本机 HTTP 服务，只提供 code/，不需要安装 npm 依赖。默认端口冲突时自动尝试后续端口，指定端口失败则明确报错，目录地址补全斜杠以保持相对模块路径正确。verify.sh 增加服务脚本语法检查。

本次未修改数学、坐标、shader 或网页业务实现。离线检查与 48 项真实 GPU 回归通过，普通地球飞行与阅读页已观察；README、HANDOFF 和 [本地运行流程](07-本地运行流程.md) 已更新。证据见 [验证报告](03-验证报告.md) 的本地复验部分。Git 基线仍未建立，当前任务未执行 GitHub 同步或发布。
