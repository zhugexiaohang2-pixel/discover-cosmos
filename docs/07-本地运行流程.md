# DiscoverCOSMOS 本地运行流程

本流程于 2026-10-13 在当前 Mac 上验证。页面不需要账号、AI API、npm 安装或构建。

## 下一次怎样启动

1. 打开 DiscoverCOSMOS 文件夹，双击 `start.command`。它会打开终端并启动本地服务。
2. 保持该终端窗口运行，复制终端显示的“星际图鉴”或“太阳系飞行”网址到浏览器。
3. 使用完毕，在服务终端按 Ctrl+C，然后关闭窗口。

也可以打开终端，输入以下命令；如果文件夹搬家，请把第一行改为新的实际位置：

~~~bash
cd "/Users/meowmeow/Downloads/DiscoverCOSMOS"
npm start
~~~

默认网址：

| 页面 | 地址 |
|---|---|
| 星际图鉴 | http://127.0.0.1:8040/index.html |
| 太阳系飞行 | http://127.0.0.1:8040/solar/index.html |
| 真实 GPU 检查 | http://127.0.0.1:8040/solar/render-check.html |

默认端口 8040 已占用时，程序自动尝试 8041–8060，并打印实际网址。再次启动可能创建另一个服务，已有页面能用时无需重复启动。需要固定其他端口时运行 `npm start -- 8050`；指定端口被占用会报错，请换一个。服务只向本机提供 code/，并不用于公开网站部署。

如果 macOS 不允许双击启动，在终端进入项目目录后执行 `bash start.command`，或直接使用 `npm start`。不要双击 index.html，因为 file:// 访问可能阻止 JavaScript 模块加载。

## 环境与检查

只看网页需要 Node.js 22+ 和支持 JavaScript、ES modules、WebGL 的现代浏览器。当前 Node.js v24.21.0 已可用，Three.js 0.160.1 随项目提供。无需 `npm install`、`npm ci` 或连接 CDN。

修改代码或换电脑后，在项目根目录运行：

~~~bash
node --version
bash verify.sh
~~~

然后启动服务，打开 `/solar/render-check.html`，等待看到“PASS：48/48 项浏览器检查通过；0 项失败”。离线断言数会随文档链接变化，以实际输出为准。GPU 检查单独执行，不能由离线检查代替。

最后打开普通太阳系页面，确认星空、太阳、轨道可见；点选地球，等待约 20 秒抵达，再点“阅读该星球”。图鉴支持直接访问 `/index.html#/p/earth` 并刷新。

本次 macOS 系统的 `/usr/bin/python3` 与 `/usr/bin/git` 因缺少 Xcode Command Line Tools 而报错，Node.js 预览不依赖它们。以后需要建立 Git 记录时，可安装 Apple 官方命令行工具，再按 HANDOFF 核对仓库目录与提交署名。当前未建立 Git 基线。

已有可用 Python 3 的电脑仍可使用原交付方式：

~~~bash
python3 -m http.server 8040 --bind 127.0.0.1 --directory code
~~~

## 常见情况

| 现象 | 处理 |
|---|---|
| 浏览器提示无法连接 | 先确认服务终端仍在运行，并使用它实际显示的端口；重启电脑后需重新启动服务 |
| 找不到 node/npm | 从 Node.js 官方网站安装 22 或更新版本，重新打开终端；有 node 时可运行 `node scripts/serve.mjs` |
| 太阳系黑屏或报 WebGL 错误 | 在支持 WebGL 的浏览器打开 GPU 检查页；可尝试 `/solar/index.html?rt=byte` 核对兼容路径 |
| 修改文件后看到旧内容 | 刷新页面；本地 Node.js 服务发送 no-store，不需要重新构建 |
| 终端打印权限错误 | 确认项目目录可读取；在助手沙箱中监听本地端口可能需要允许启动本地服务 |
