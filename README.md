# 星际探索局 · DiscoverCOSMOS 交付包

这是一个面向青少年的太阳系科普网页项目。观众可以阅读八大行星图鉴，也可以进入三维太阳系，飞向某颗行星，观察接近光速时星空方向、颜色和亮度的变化。

本文件夹包含当前可运行代码、产品与技术说明、检查证据、历史备份，以及接手 agent 的操作指南。交付日期为 2026-10-13。

## 从哪里开始读

如果你主要负责理解、介绍或展示产品，按下面的顺序阅读即可，不需要先学编程：

1. [产品介绍与设计逻辑](docs/01-产品介绍.md)：为什么做、给谁用、界面为什么这样安排。
2. [技术方案通俗说明](docs/02-技术方案.md)：网页由什么组成，怎样画出行星，技术名词是什么意思。
3. [相对论飞行与背景星空](docs/05-相对论飞行与背景星空.md)：核心特色、星星的生成方法，以及真实与演示之间的取舍。
4. [公式读本](docs/06-公式读本.md)：逐条解释公式，不要求推导或计算。

需要核对交付状态时，阅读 [验证报告](docs/03-验证报告.md) 和 [检查与修复记录](docs/04-检查与修复记录.md)。需要继续开发或发布网页时，让 agent 阅读 [HANDOFF](HANDOFF.md)。

这里的 agent 指能读取文件、修改代码和执行命令的编程助手。产品本身不需要 agent 或 AI 服务才能运行。

## 怎样把项目交给下一位助手

把整个文件夹解压到电脑上，在编程助手中选择这个文件夹作为工作目录，然后给它这段话：

> 请先阅读 README.md、AGENTS.md 和 HANDOFF.md，接手 DiscoverCOSMOS。先检查代码并建立本地 Git 版本记录，再按 HANDOFF 向我询问 GitHub 账号、仓库与公开发布安排。得到我的答复后，同步到 GitHub，并配置 GitHub Actions 与 GitHub Pages。完成后给我能够直接访问的网页链接和验证结果。

如果对方主要负责讲解产品，把 docs 文件夹交给他即可。涉及继续开发或上线时，应交付整个文件夹，尤其不要漏掉 code/vendor 中的 Three.js 文件和许可证。

## 怎样查看网页

**线上查看：** 本交付包还没有公开网址。接手 agent 完成 HANDOFF 中的 GitHub Pages 发布流程后，普通观众只需点击网址，不需要安装编程工具。

**本地查看：** 需要 Node.js 22+ 和支持 WebGL 的现代浏览器。macOS 可双击本文件夹中的 `start.command`，也可以在本文件夹的终端运行：

~~~bash
npm start
~~~

保持启动终端运行，按 Ctrl+C 停止。默认端口是 8040；被占用时自动尝试 8041–8060，请使用终端实际显示的网址。完整的启动、停止、检查与排障步骤见 [本地运行流程](docs/07-本地运行流程.md)。无需 npm install。

已有可用 Python 3 时，也可以沿用交付方式：

~~~bash
python3 -m http.server 8040 --bind 127.0.0.1 --directory code
~~~

随后打开 [星际图鉴](http://127.0.0.1:8040/index.html) 或 [太阳系飞行](http://127.0.0.1:8040/solar/index.html)。如果你不熟悉终端，可以让接手 agent 代为启动；端口被占用时由它换一个端口。

双击 HTML 文件不等同于通过网页服务访问，浏览器可能阻止模块加载。Three.js 已在本地，无需连接 CDN、安装 npm 依赖或构建项目。

| 操作 | 作用 |
|---|---|
| 点击图鉴卡牌 | 打开对应行星的阅读页 |
| 拖动阅读页球体 | 旋转球体插画 |
| 点击太阳系中的行星或名称 | 连续飞抵该行星 |
| 在太阳系画面中拖动 | 改变环绕角度 |
| 滚轮 | 调整观察距离 |
| Esc | 返回内太阳系俯瞰 |
| H 或参数面板按钮 | 调整飞行与显示参数 |

## 文件夹说明

| 内容 | 用途 |
|---|---|
| code/ | 发布到网页上的文件，含本地 Three.js |
| docs/ | 人可以阅读的解释、报告、流程图与证据 |
| HANDOFF.md、AGENTS.md | 接手 agent 的工作说明 |
| package.json、verify.sh | 开发与交付检查入口 |
| start.command、scripts/serve.mjs | macOS 启动入口与无安装依赖的 Node.js 本地预览服务 |
| templates/pages.yml | 待启用的 GitHub Actions 发布模板 |
| archive/ | 本次检查前的原始备份 |
| `交付清单.json` | 打包时的文件清单与校验值 |

GitHub 发布时，网页内容来自 code/，不把整个交付目录当作网站首页。[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) 适合托管本项目这种由 HTML、CSS 和 JavaScript 组成的静态网站。
